migrating this site to astro + mdx

2026 jul 28

for a while this site was one hand-rolled build script: data/resume.json in, static html out, zero runtime dependencies. that was the right tradeoff when the only content was a resume.

it stopped being the right tradeoff the moment I wanted a blog. adding a post meant either hard-coding another html string into build.js or growing a templating layer myself. astro already has that layer, plus a content collection that treats a folder of .mdx files as a typed, sorted list, so this post is also the test case for the migration that shipped it.

the terminal look, the accent color, the contrast tuning: none of that changed. only the thing generating the html did.
